# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, and keep discussion about the module. Harassment, insults and personal attacks aren't welcome in issues, pull requests or anywhere else the project is discussed.

If someone's behaviour worries you, open an issue or contact the maintainer through their GitHub profile. Reports are handled privately, and the maintainer may edit or remove comments, or block people, who don't follow this code.
